## 逐份点评

### ChatGPT — 10.0

整体布局和视觉平衡出色。咖啡机的立体感、桌面纵深、杯子与电子秤的摆放都比较自然。四个指定动作清楚，指示挂钟的触手末端几乎贴着钟面（实测 8.1px），剩余肢体也有区分。本轮的满分作品。

### ZCode — 9.5

细节最充分，咖啡机、桌面、奶壶和触手的层次比较丰富。源码还明确区分了八条触手的用途，与画面基本吻合。指钟的触手方向最准，末端离钟面 45px。扣分在身体附近触手交叠。

### WorkBuddy — 9.5

指令执行非常扎实：奶壶有触手承接，奶流进入杯中，杯子在电子秤上，另一条触手连接咖啡机的手柄区域。扣分在指向——触手本体离钟面还有 107px，靠一条紫色虚线示意线补足，属于用标注代替绘制。

### DeepSeek Harness — 9.5

基本任务齐全，八条触手也能辨识，指示挂钟的触手末端离钟面 17.5px。扣分在身体附近部分触手交叠，并延伸到桌面前沿。

### Claude — 9.5

构图简洁，主要对象一眼就能看清。扣分在奶壶——壶看起来悬浮在空中，没有任何触手接触它。这是在 20 项里只值 0.5 分，但视觉上一眼就能看出。

## 这次测出了什么

同一个提示词下，可以观察到三种不同表现：

- **完整执行型**：能把各项要求都安排到画面中，并让物体之间存在合理关系。
- **视觉表达型**：画面很完整，但个别动作依靠视觉暗示，实际接触关系并不充分。
- **表面完成型**：物件和动作看起来都在，但触手抓握、空间遮挡等细节经不起仔细检查。

五份成绩都在 9.5 以上，单凭一次结果不能断言哪个 Agent 工具更强。下一轮建议每个 Agent 独立运行三次，固定提示词、模型参数和输出要求，再比较平均分与最低分。
