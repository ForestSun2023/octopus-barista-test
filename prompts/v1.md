Create a self-contained SVG illustration of an octopus working as a barista in a coffee shop. The illustration must satisfy ALL of these constraints:

The octopus has exactly eight distinct, clearly visible tentacles, with no merged or duplicated limbs.
One tentacle holds a portafilter correctly positioned under an espresso machine.
One tentacle pours milk from a pitcher, with a continuous visible stream entering a coffee cup.
One tentacle presses a button on the espresso machine.
One tentacle points toward a wall clock.
The coffee cup rests directly on a digital scale, which stands on the countertop.
The espresso machine also rests on the countertop.
All objects must have physically plausible positions and orientations.
The remaining four tentacles must be clearly visible and anatomically connected to the octopus.
Use a front three-quarter perspective, with clear object boundaries, sensible occlusion, and consistent proportions.
Output valid, self-contained SVG code with a viewBox.
Use SVG vector elements only, without raster images, external assets, or embedded base64 images.
Do not omit any constraint to simplify the drawing.
Prioritize structural correctness and spatial relationships over decorative detail.
Return the complete SVG code only.
