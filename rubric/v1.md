# 评分表 v1（已冻结）

> 2026-10-13 那一轮发布的 9.5 / 9.4 / 9.2 / 8.3 / 7.8 就是用这一版打出来的。
> **不要再改动本文件**，否则已发布分数就失去口径。当前版本见 [v2.md](v2.md)。

## 计分口径

4 类加权（5 + 2 + 2 + 1），**不是**下面 10 项直接相加。

| 评分项目 | 满分 | 主要检查内容 |
| --- | --- | --- |
| 指令完成度 | 5 | 八条触手、四项指定动作、其余肢体是否齐全 |
| 空间与交互关系 | 2 | 抓握、倒奶、按钮接触、杯子和秤的关系 |
| 构图与视觉表达 | 2 | 遮挡、透视、比例、可辨识度及细节 |
| SVG 工程质量 | 1 | XML 有效性、自包含性、能否正常渲染 |

## 10 项检查清单

| # | 测试项目 | 通过标准 |
| --- | --- | --- |
| 1 | 代码质量 | SVG 合法、自包含，能正常渲染 |
| 2 | 肢体数量 | 八条触手数量准确，彼此可区分 |
| 3 | 物体抓取 | 触手与手柄的接触关系合理 |
| 4 | 液体流向 | 牛奶连续流入杯内，而非悬空或流到杯外 |
| 5 | 按钮交互 | 触手确实接触咖啡机按钮 |
| 6 | 指向关系 | 触手方向明确指向挂钟 |
| 7 | 杯子与秤 | 杯子直接放在电子秤上 |
| 8 | 场景支撑 | 咖啡机和电子秤均落在台面上 |
| 9 | 肢体连接 | 剩余四条触手清晰可见且连接正确 |
| 10 | 空间关系 | 前后遮挡合理，物体没有明显穿插 |

## 人工项的判定证据

| 项目 | 怎么算过 |
| --- | --- |
| 肢体数量 | 从身体出发把 8 条触手逐个编号，编号时不能出现「这里算一条还是两条」的犹豫 |
| 物体抓取 | 手柄图形与触手末端贴合；「靠近」不算 |
| 液体流向 | 奶流是一条连续路径，终点落在杯口内；中段断开或落到杯外都算不过 |
| 按钮交互 | 触手末端压在按钮图形上，而不是停在按钮旁边 |
| 指向关系 | 触手的轴线延长线穿过钟面 |
| 杯子与秤 | 杯底与秤台面贴合，中间看不到台面 |
| 场景支撑 | 咖啡机、秤的底边与台面线重合 |
| 肢体连接 | 四条剩余触手的起点在身体上，不是从画面外伸进来 |
| 空间关系 | 遮挡前后一致：同一条触手不能既在机器前又在机器后 |

## v1 已知的两个缺陷

1. 计分口径（4 类加权）和检查清单（10 项二值）不是同一套东西，用清单复现不出已发布的分数。
2. 清单漏了评审实际在用的两条判据：**奶壶抓握**（Claude 被扣最多就是因为这个）和**触手大面积交叠**（ZCode 被扣的理由）。另外指向关系只写了「方向明确」，没写末端可以离钟面多远。

v2 修的就是这两条。详见 [../results/EVIDENCE.md](../results/EVIDENCE.md) 与 [../results/BLIND.md](../results/BLIND.md)。
